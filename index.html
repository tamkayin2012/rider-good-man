Quick GitHub Pages Setup:

  1. Create a new repository on GitHub (e.g., youth-elite-monitoring).
  2. Unzip the downloaded bundle and upload index.html, README.md, and .nojekyll.
  3. Go to Settings → Pages → Build and deployment, select Deploy from a branch (main / root), and click Save.
